# Power GIS Icons

Bộ icon SVG line-style cho GIS điện lực, dùng tốt với OpenLayers, Leaflet, MapLibre hoặc Next.js.

## Danh sách
- transformer.svg — Trạm/máy biến áp
- substation.svg — Trạm điện / trạm biến áp
- transmission-tower.svg — Cột điện cao thế
- utility-pole.svg — Cột điện phân phối
- power-line.svg — Đường dây điện
- power-plant.svg — Nhà máy điện
- solar-plant.svg — Điện mặt trời
- wind-turbine.svg — Điện gió
- hydropower.svg — Thủy điện
- battery-storage.svg — Hệ thống lưu trữ pin
- ev-charger.svg — Trụ sạc xe điện
- charging-station-area.svg — Điểm/trạm sạc trên bản đồ
- electric-meter.svg — Công tơ điện
- distribution-box.svg — Tủ điện / tủ phân phối

## Kỹ thuật
- viewBox: 0 0 24 24
- fill: none
- stroke: currentColor
- stroke-width: 1.8
- Có thể đổi màu bằng CSS nếu inline SVG.

## Gợi ý màu theo cấp điện áp
- <= 35kV: #22C55E
- 110kV: #3B82F6
- 220kV: #F59E0B
- 500kV: #EF4444

Bạn có thể chỉnh lại bộ màu theo quy ước nghiệp vụ của dự án.
